    Cómo funciona

    De la web del supermercado a la recomendación.

    Detrás del comparador hay un pipeline de datos en cuatro etapas que se ejecuta con un solo comando (run_pipeline.py): actualizar los precios no requiere tocar código.

    01scraping

    Extracción

    —
    productos extraídos

    Scrapers que leen las APIs internas de cada tienda online, con paginación, reintentos y pausas aleatorias entre peticiones.

    scrapers/*.py
    02limpieza

    Normalización

    —
    con marca y formato identificados

    De cada nombre se extrae marca, tipo de marca y formato. Todo se convierte a litros o kilos para comparar precio por unidad.

    normalizer.py
    03emparejado

    Matching

    —
    productos presentes en varias cadenas

    Dos productos se consideran el mismo solo si coinciden marca, tipo de marca, tamaño y descripción.

    matcher.py · promoter.py
    04cálculo

    Optimización

    —
    cadenas, cada una con su envío

    Se prueban todas las formas de repartir la cesta entre cadenas y se suma el envío que aplica cada una.

    FastAPI · POST /optimize
